# Цели освоения дисциплины «DevOps»

## Личные цели на семестр
1. **Освоить продвинутую работу с Git:** научиться уверенно разрешать конфликты слияния, использовать `rebase`, `cherry-pick`, `reflog` и вести чистую историю коммитов.
2. **Изучить контейнеризацию:** понять принципы работы Docker, научиться оптимизировать `Dockerfile` и управлять многоконтейнерными приложениями через Docker Compose.
3. **Освоить CI/CD:** настроить автоматическое тестирование, сборку и развертывание приложений с использованием GitHub Actions и GitVerse.
4. **Понять концепцию Infrastructure as Code (IaC):** ознакомиться с базовыми принципами работы Terraform и Ansible.

## Ключевые показатели успешности (KPI)
* Выполнить все практические и контрольные работы вовремя.
* Автоматизировать деплой хотя бы одного личного или учебного проекта.
* Сформировать аккуратный портфолио-репозиторий на GitHub/GitVerse.
